# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2025-06-09

### Added

- Initial version of the `bingems` project.
- Zurich weather and sport forecaster (`weather_sport_forecaster.py`).
- `justfile` for easy installation and execution.
- `pyproject.toml` for dependency management with `uv`.
- `README.md`, `AI_REASONING.md`, and `GEMINI.md` for project documentation.
- `.env.example` to document required environment variables.
