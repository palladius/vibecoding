# vibecoding

Apps created with vibecoding, one folder each.

## Projects

- `apps-portfolio`: A portfolio application to showcase demos and talks.
- `apps-portfolio-broken`: A broken version of the portfolio application (for debugging/demonstration).
- `bingems`: A collection of binary executables that use Gemini LLM.
- `german-card-game`: A German card game project.
- `magic-bookmark`: A Chrome extension for magic bookmarks.
- `research`: Research-related files.
- `ruby-serper-mcp-server`: A Ruby server for Serper MCP.
- `vibecheck`: An application to check system health and perform maintenance.
